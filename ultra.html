Ultra

Every trail in Pacific Spirit, in one run from the Park Centre

One route that runs every trail in the park at least once, starting and finishing at the Park Centre (the ranger station on Cleveland Trail at W 16th Ave). It’s also the aid station: park for free along W 16th Ave, right in the middle of the park, and there are toilets and drinking water. The route comes back past it along the way.

An optional second aid station fits where Imperial Trail meets W King Edward Ave and W 29th Ave (the grey pin): there’s street parking by the trailhead, and toilets. It takes a second car, so don’t count on it, but it breaks up the long stretch between passes of the Park Centre.

function kmRange([a, b]) {
  const [from, to] = [Math.round(a), Math.round(b)];
  return from === to ? `km ${from}` : `km ${from}–${to}`;
}

// "start, km 19–21, km 51, finish" for the Park Centre; just the km elsewhere.
function aidPasses(name, stops) {
  const kms = stops.map(kmRange);
  return name === "Park Centre" ? ["start", ...kms.slice(1, -1), "finish"].join(", ") : kms.join(", ");
}

// Aid station passes (km), the sure ones or the optional ones.
function aidKm(optional) {
  return Object.entries(stats.aid)
    .filter(([name]) => stats.aid_optional.includes(name) === optional)
    .flatMap(([, stops]) => stops.map(([a]) => a));
}

// Labels for the passes mid-run, at the top of the profile.
function aidLabels(optional) {
  return aidKm(optional).filter((km) => km > 0 && km < stats.km).map((km) => ({km}));
}

function onTheWay(kind) {
  return stats.on_the_way.filter(([, , kinds]) => kinds.includes(kind)).map(kmRange);
}

// What's at this km, for the tooltip.
function whatsHere(km) {
  const near = (a, b = a) => a - 0.15 <= km && km <= b + 0.15;
  const what = Object.entries(stats.aid)
    .filter(([, stops]) => stops.some(([a, b]) => near(a, b)))
    .map(([name]) => `${stats.aid_optional.includes(name) ? "optional aid station" : "aid station"} (${name})`);
  what.push(...amenity.passedNear(stats.passes_by, km));
  return what.length ? ` · ${what.join(", ")}` : "";
}

function ultraGpx(name, coordinates) {
  const points = coordinates.map(([lon, lat]) => `<trkpt lat="${lat}" lon="${lon}"></trkpt>`);
  return `<?xml version="1.0" encoding="UTF-8"?>
<gpx version="1.1" creator="psp-trails" xmlns="http://www.topografix.com/GPX/1/1">
  <trk>
    <name>${name}</name>
    <trkseg>
      ${points.join("\n      ")}
    </trkseg>
  </trk>
</gpx>`;
}

Where this idea comes from

Running every trail in Pacific Spirit as one ultra isn’t our idea: there’s an existing Pacific Spirit Park ultra route that inspired this page. We’ll link it, and its GPX, here. What’s on this page is our own version, worked out from the trail data by code.

How it’s made

Finding the shortest run that covers every trail is a classic puzzle, the route inspection or “Chinese postman” problem. Every junction needs as many ways in as ways out; where a junction doesn’t have that (a dead end, or three trails meeting), some stretch has to be run twice, or linked up by road. It’s an ultra already, so a bit of road beats running a trail a second time: the script (08_plan_ultra.py) counts a repeat as 2½ times the distance and road as 1½ times (Imperial Drive and W 29th Ave, which we run anyway, count the same as trail), picks the cheapest way to join everything up, and walks it all as one loop from the Park Centre. It only turns straight back at a dead end; dead-end offshoots of up to 400 m are marked optional. It uses the same trail data and edits as the route of the day; see About.
