Ultra

Every trail in Pacific Spirit, in one run from the Park Centre

One route that runs every trail in the park at least once, starting and finishing at the Park Centre (the ranger station on Cleveland Trail at W 16th Ave). It’s also the aid station: park for free along W 16th Ave, right in the middle of the park, and there are toilets and drinking water. The route comes back past it along the way.

function kmRange([a, b]) {
  const [from, to] = [Math.round(a), Math.round(b)];
  return from === to ? `km ${from}` : `km ${from}–${to}`;
}

function onTheWay(kind) {
  return stats.on_the_way.filter(([, , kinds]) => kinds.includes(kind)).map(kmRange);
}

ICONS = {
  // The same marks as the trail map: a yellow "WC" dot, a magenta "W" dot.
  const R = 2, D = 22; // pixel ratio; one dot, in CSS px
  function dot(ctx, cx, color, letters) {
    ctx.beginPath();
    ctx.arc(cx, D / 2, D / 2 - 1.5, 0, 2 * Math.PI);
    ctx.fillStyle = color;
    ctx.fill();
    ctx.lineWidth = 2;
    ctx.strokeStyle = "#fcfcfb";
    ctx.stroke();
    ctx.fillStyle = "#0b0b0b";
    ctx.font = "700 9px system-ui, -apple-system, sans-serif";
    ctx.textAlign = "center";
    ctx.textBaseline = "middle";
    ctx.fillText(letters, cx, D / 2 + 0.5);
  }
  function icon(...dots) { // dots side by side
    const width = D + (dots.length - 1) * 16;
    const canvas = Object.assign(document.createElement("canvas"), {width: width * R, height: D * R});
    canvas.style.width = `${width}px`;
    const ctx = canvas.getContext("2d");
    ctx.scale(R, R);
    dots.forEach(([color, letters], i) => dot(ctx, D / 2 + i * 16, color, letters));
    return canvas;
  }
  const toilets = ["#eda100", "WC"], water = ["#e87ba4", "W"];
  return {toilets: icon(toilets), water: icon(water), both: icon(toilets, water)};
}

function gpx(name, coordinates) {
  const points = coordinates.map(([lon, lat]) => `<trkpt lat="${lat}" lon="${lon}"></trkpt>`);

  <trk>
    <name>${name}</name>
    <trkseg>
      ${points.join("\n      ")}
    </trkseg>
  </trk>
</gpx>`;
}

Where this idea comes from

Running every trail in Pacific Spirit as one ultra isn’t our idea: there’s an existing Pacific Spirit Park ultra route that inspired this page. We’ll link it, and its GPX, here. What’s on this page is our own version, worked out from the trail data by code.

How it’s made

Finding the shortest run that covers every trail is a classic puzzle, the route inspection or “Chinese postman” problem. Every junction needs as many ways in as ways out; where a junction doesn’t have that (a dead end, or three trails meeting), some stretch has to be run twice, or linked up by road. It’s an ultra already, so a bit of road beats running a trail a second time: the script (08_plan_ultra.py) counts a repeat as 2½ times the distance and road as 1½ times (Imperial Drive and W 29th Ave, which we run anyway, count the same as trail), picks the cheapest way to join everything up, and walks it all as one loop from the Park Centre. It only turns straight back at a dead end; dead-end offshoots of up to 400 m are marked optional. It uses the same trail data and edits as the Routes page; see About.
